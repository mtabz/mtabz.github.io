What this shows

MCPFence identifies the urgent finding: an occupied npm package that requests credentials and exposes state-changing tools. It records directory provenance gaps and an unclaimed PyPI name separately, so the vendor can act in risk order.

Why several directories?

MCP servers are listed in several independent catalogues. The same vendor can appear under different names in each one, so MCPFence assesses every listing as a separate identity surface.
