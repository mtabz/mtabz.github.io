What the command does

One command turns vendor identity hints into an exposure map.

InputVendor name plus any known official package, endpoint, GitHub organisation or domain.
ResolutionQueries npm, PyPI and the official MCP Registry, then applies deterministic name and provenance rules.
OutputWrites a human-readable audit report and a machine-readable exposure map from the same scan.
SafetyReads registry metadata only; it does not install or execute unknown packages.
